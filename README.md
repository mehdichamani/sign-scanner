# سامانه هوشمند تولید برگه و استخراج امضا (Sign Scanner Pro)

یک وب‌اپلیکیشن خودکار و پیشرفته برای **تولید برگه‌های اخذ امضای پرسنلی در قالب PDF** و سپس **اسکن، تشخیص، پیش‌نمایش زنده و استخراج امضاها با پس‌زمینه شفاف (PNG)** با استفاده از بارکد ۲بعدی (QR Code) و پردازش تصویر هوشمند (OpenCV).

---

## 🚀 شروع سریع و آسان

تنها کافیست روی فایل `run.bat` دوبار کلیک کنید یا دستور زیر را در خط فرمان اجرا نمایید:

```bash
python main.py
```

مرورگر وب شما به‌صورت خودکار باز شده و پنل برنامه در آدرس `http://localhost:8080` در دسترس خواهد بود.

---

## 🗂 ساختار پروژه (Project Structure)

```plaintext
sign-scanner/
│
├── src/

│   ├── generator.py           # موتور تولید PDF برگه‌های امضا

│   └── utils.py               # توابع کمکی متن فارسی

│   └── employees.sample.csv   # داده‌های نمونه پرسنل
│
├── scans/                     # پوشه تصاویر اسکن‌شده (ورودی)
├── output/                    # پوشه خروجی‌ها (تولید PDF و امضاهای PNG)

```

## 📋 امکانات پنل وب

### ۱. 📄 تولید برگه امضا (PDF Generator)
- امکان مشاهده، ویرایش زنده و افزودن پرسنل جدید به جدول.
- امکان بارگذاری فایل CSV جدید یا استفاده از داده‌های پیش‌فرض.
- تولید آنی برگه A4 استاندارد (شبکه ۳ در ۴) با بارکد QR و چیدمان بر اساس واحد سازمانی.
- دانلود یا مشاهده مستقیم فایل PDF در مرورگر.

### ۲. 🎯 استخراج و برش هوشمند امضا (Signature Extractor)
- انتخاب فایل‌های اسکن‌شده از پوشه `scans/`.
- تشخیص خودکار کادرهای امضا و خواندن کدهای پرسنلی از روی بارکدها.
- ابزارهای ترسیم و جابجایی دستی کادرها روی تصویر بوم با امکان بزرگنمایی و چرخش.
- پیش‌نمایش زنده شفاف‌سازی امضا همراه با تنظیم حساسیت آستانه حذف پس‌زمینه و حاشیه کادر.
- ذخیره تکی یا دسته‌جمعی امضاها به صورت فایل شفاف PNG در پوشه `output/signatures/`.
